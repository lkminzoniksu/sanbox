About Hotel PieCharm

Hotel PieCharm was developed as part of the Integrated Computer Science program at Kansas State University.

This project demonstrates:

  • Object-Oriented Programming
  • Inheritance
  • Interfaces
  • Abstract Classes
  • Tkinter GUI Development
  • Flask Web Development
  • JSON Persistence
  • Unit Testing with Pytest

Developed by Lucas Minzoni.
